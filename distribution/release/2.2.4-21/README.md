## لماذا هذه النسخة مهمّة

2.2.3 (20) بُنيت من فرع لم يكن مدموجاً مع `main`، فشُحنت **ناقصةً**: بلا UMP، وبلا
ترقية SDK الإعلانات، وبلا استعادة المشتريات. تُحقّق من ذلك بفحص حزمتها المسحوبة من
جهاز حقيقي (صفر `canRequestAds`، SDK 23.6.0). **2.2.4 هي أوّل نسخة تصل المتجر
حاملةً هذه الثلاثة.**

## ما فيها

- **استعادة المشتريات**: الاشتراك يُستعاد تلقائياً عند الدخول على جهاز جديد، مع زر يدوي
- **مقاس البانر الخاطئ** — عُلّة مرصودة على جهاز حقيقي: كان يُطلب بعرض 832dp
  (ارتفاع الشاشة لا عرضها) فيُقابَل بـ `No fill`، ويتذبذب فيهدم الإعلان ويعيد بناءه.
  العرض صار يُقاس من التخطيط عبر `BoxWithConstraints`
- **UMP**: نموذج موافقة الخصوصية + مدخل «خيارات خصوصية الإعلانات» في الإعدادات ←
  الخصوصية. تهيئة SDK صارت **بعد** حسم الموافقة وعلى خيط خلفي
- ترقية SDK الإعلانات 23.6.0 → 24.8.0 (السقف مع Kotlin 2.0.21)
- إصلاح بانر يختفي عند إعادة ترتيب قائمة المحادثات (`key(slot)`)
- فجوة 16dp بين بانر الاكتشاف وأزرار التمرير — درءاً للنقر العرضي
- عرض اهتمامات المستخدم في شاشة ملف الآخرين

## قبل الرفع

**أنشئ نموذج GDPR في AdMob ← Privacy & messaging.** السجل يؤكّد غيابه في كل إقلاع:
`Publisher misconfiguration: no form(s) configured for the input app ID … ~7977406362`.
بدونه يُشحن كود UMP بلا نموذج يعرضه، ويبقى مستخدمو أوروبا بلا إعلانات.
