# Hala 2.5.0 (26) — نسخة الرفع

- الحزمة: `com.chathala.hala`، الحد الأدنى Android API 32، الهدف API 36.
- آخر إصدار في Google Play: 2.4.1 (25)، أكده المستخدم في الجلسة.
- ملاحظات المتجر بالعربية والإنجليزية بجانب هذا الملف.
- الحزمة المطلوبة للمتجر: `artifacts/app-release.aab`؛ APK للتجربة فقط.

## التغييرات

مسودات المحادثات وإعادة المحاولة اليدوية للنصوص والصور والتسجيلات الفاشلة، وتحسين المزامنة وحماية بيانات الجلسات والاشتراكات، وبطاقات إعلانات أوضح وبانرات متكيفة وتخفيف مقاطعة التصفح، وإضافة Unity SDK والمحوّل عبر AdMob.

تستخدم Release معرّفات AdMob الإنتاجية وتستبعد فاحص الإعلانات وحقول اختبار الأجهزة. Unity تطلب إعلانات غير مخصصة عالمياً (`privacy.consent=false`) قبل التهيئة وبعد تحديث خيارات UMP، دون منح موافقة افتراضية. يبقى سماح UMP ومعرفة أن المستخدم غير مشترك شرطين لطلبات الإعلانات.

## إعداد الحساب

أتمّ المستخدم إنشاء مجموعتي Hala Unity Banner وHala Unity Interstitial، مع Android Game ID `800402856` والموضعين `BP_Banner_Android` و`BP_Interstitial_Android`. وقد تحقق بصور اللوحة من وجود Unity Ads في شركاء أوروبا والولايات الأمريكية. لا يوجد مسار Rewarded في التطبيق.

المتبقي خارج الحزمة:

- آخر حالة تفعيل المجموعتين بعد طلب تعطيلهما مؤقتاً غير مؤكدة. لا تُحذف شبكة AdMob منهما.
- أُكمل ملف https://www.chathala.com/app-ads.txt على السيرفر في 18 أكتوبر 2026 بإضافة 161 سجل بائع من قائمة Unity التي أرسلها المستخدم، مع الحفاظ على سطر Google. تأكد الرد HTTP 200 وظهور السجلات الـ162. بقي تأكيد قبول الملف بعد إعادة فحص Unity.
- لا جهاز متصل: لم تُختبر استجابة Unity أو واجهتها فعلياً. استخدم وضع اختبار Unity على جهاز مسجل وفاحص الإعلانات في Debug للتحقق، ثم تأكد من إيقاف الاختبار العام قبل طرح الإنتاج.
- راجع رسالة US states لتطبيق Hala وإفصاحات Data safety/سياسة الخصوصية مقابل SDK الجديد؛ إدراج الشريك وحده ليس إثبات اكتمال الرسالة.

## الرفع

لم تُرفع هذه النسخة آلياً: محاولتا الوصول إلى Chrome انتهتا بمهلة، والتبويب المنفصل لم يصل إلى جلسة Play Console المصادق عليها. افتح Hala في حسابك → مسار الإصدار المطلوب → Create new release، وارفع AAB والصق ملاحظات الإصدار من الملفين، ثم راجع فحص Google قبل إرسال النسخة للمراجعة.

نجح بناء Release كاملاً، ونجح 61 اختباراً. انتهى lint دون أخطاء (145 تحذيراً و6 تلميحات). نجح التحقق من توقيع AAB وAPK، وفُحصت محاذاة 12 مكتبة ELF فكانت جميعها 16 KiB أو أكثر. التحقق المحلي والتوقيع وبصمة SHA-256 مُسجّلة في `artifacts/build-info.txt` وملف التحقق المرافق بعد اكتمال البناء. لا تتضمن الحزمة أي مفاتيح توقيع أو كلمات مرور.
